# 保真验证

`audio_tools.py` 只测量，不修改音频。numpy/scipy/soundfile 即可运行；`--pitch` 另需 librosa。未加参数时 `pitch_status` 为 `not_measured`，不能声称音调已验证。

## 参考选择

比较区间是**原录音相同时间位置**的目标独白且噪声很低的片段。另录声纹只能识别身份，不能校准原录音音量/频谱。没有可信区间时，标为无法测出目标源的原始保真变化；仍可检查格式、时间轴和明显失真。

采样率、声道数或样本数不同，脚本不做区间差异计算。先确认/修复已知延迟，不用变速强行对齐。模型固定尾部 padding 可裁掉并记录，真实内容长度差异不能补零掩盖。

## 指标

- 各通道 RMS、峰值 dBFS、接近满刻度的样本数；满刻度统计不是模拟削波的完整诊断。
- 独白区间 RMS 差、50 ms 窗口 RMS 差的 95 分位。不匹配增益、不归一化；混合区间不能代表目标响度。
- 同一时间区间的对数谱差，仅统计原音相对强的时频点。可能包含残留噪声变化，不是真实纯目标误差。
- 可选 pYIN F0：共同有声帧的音分差及有声帧保留比例。无可靠有声帧时未验证。默认 F0 搜索 60–600 Hz，特殊声线应调整，不作为医学/声乐测量。
- 默认复核提示：区间 RMS 差 <= 0.5 dB、窗口差 95 分位 <= 1 dB、谱差 <= 1 dB；启用 F0 时音分差 95 分位 <= 20、有声帧保留 >= 0.95。这些不是行业保真标准，也不意味着用户接受误差。

## 听感与残差

以相同固定播放增益听原声和输出，不分别归一化。检查目标身份、字词、弱辅音、词尾、气息、音色、瞬态、金属音、泵动和声场；听 `原始 - 输出` 是否漏目标字词。分别报告背景人声残留与目标误删。MOS、SNR、SI-SDR 都不能证明全部条件成立，SI-SDR 尤其对增益不敏感。

无录音校准及干净目标源时，不能证明真实声压级、全频谱、重叠区间或“零失真”。没有实测音频、模型推理或听音条件时如实记录，不把合成测试通过当作真人处理效果证明。
